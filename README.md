## 📋 Sobre o Projeto

Site portfólio desenvolvido do zero com HTML, CSS e JavaScript puros — sem frameworks, sem dependências externas além de uma fonte do Google Fonts. O objetivo é apresentar minha trajetória, stack técnica, projetos e formas de contato de forma profissional e responsiva.

---

## ✨ Funcionalidades

- **Typewriter animado** — rotação de títulos profissionais na seção Hero
- **Animações de scroll** — elementos surgem suavemente com IntersectionObserver
- **Navbar responsiva** — menu hambúrguer para mobile com destaque do link ativo
- **Sombra dinâmica na nav** — ativada ao rolar a página
- **Botão "Voltar ao topo"** — aparece após 400px de scroll
- **Design totalmente responsivo** — adaptado para mobile, tablet e desktop
- **Orbs animados** — fundo com gradientes em movimento (CSS puro)

## 📦 Como Rodar Localmente

Não há dependências nem etapa de build. Basta clonar e abrir:

```bash
git clone https://github.com/Rafafelbrown/rafafelbrown.github.io.git
cd rafafelbrown.github.io
# Abra o index.html no navegador — ou use a extensão Live Server no VS Code
```

## 🚀 Deploy

O site é hospedado via **GitHub Pages** a partir da branch `main`. Para publicar atualizações:

```bash
git add .
git commit -m "feat: descrição da mudança"
git push origin main
```

Aguarde 1–2 minutos e acesse [rafafelbrown.github.io](https://rafafelbrown.github.io) para ver as alterações.
